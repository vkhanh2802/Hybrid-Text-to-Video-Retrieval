# Tài liệu KIS Framefinder

Tài liệu được duy trì cùng mã nguồn:

- [Cấu trúc dữ liệu AIC](data/DATASET.md): nguồn, định danh keyframe,
  cấu trúc artifact, các ràng buộc mapping/index.
- [Cấu trúc repo và bảo trì](maintenance/REPOSITORY.md): vai trò từng thư mục,
  script khởi động, công cụ cũ và phạm vi dọn dẹp an toàn.
- [README dự án](../README.md): cài đặt, chạy local và kết nối DRES.

Các báo cáo, notebook và ghi chú thử nghiệm lịch sử trong workspace local
không thuộc hướng dẫn demo chính. Không dùng thông số triển khai cũ trong các
báo cáo đó để thay thế `config/models.json` và `config/pipeline.json` hiện tại.
